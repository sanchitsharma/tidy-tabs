Tidy Tabs AI

Tabs grouped by what you're actually doing

A free, open-source Chrome extension. One click groups the tabs in your window by task, puts related tabs side by side, and turns each task into a named tab group.

  • Groups by task ("Lisbon trip", "Python asyncio"), not just by website.
  • Uses your own Claude subscription via Claude Code: pick Haiku, Sonnet, Opus or any model. No API key, no server of ours.
  • Or run it on a local model with Ollama, or Chrome's built-in Gemini Nano.
  • Reuses its own groups when you tidy again; never renames yours.

Get it

  1. Install Tidy Tabs AI from the Chrome Web Store.
  2. For Claude, install the helper once (macOS or Linux): see the setup guide.

Privacy

Only tab titles and hostnames are sent, to the model you choose, when you click Tidy. The developer receives nothing. Privacy policy.
