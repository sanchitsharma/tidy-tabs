Tidy Tabs AI

Setup guide

Tidy Tabs AI's Claude backend talks to Claude Code on your computer through a small helper. Install it once.

1. Before you start

  • macOS or Linux, with Chrome, Chromium, Brave, Edge or Vivaldi (Dia and Phi on macOS too). Windows isn't supported for the Claude helper yet.
  • Claude Code installed and logged in: run claude once in a terminal.
  • Node.js 18 or newer.
  • The Tidy Tabs AI extension.

2. Install the helper

Paste this into a terminal:

curl -fsSL https://github.com/sanchitsharma/tidy-tabs/releases/latest/download/install.sh | bash

It copies the helper into your user folder (no sudo), finds claude and node, and registers the helper with each supported browser it finds. If it can't find them, pass paths: add -s -- --claude /path/to/claude --node /path/to/node after bash.

3. Restart the browser

Fully quit the browser (not just the window) and reopen it, so it picks up the helper. Then click the Tidy Tabs AI toolbar icon and press Tidy now. In Options, Test connection checks the helper.

Choose a model

In the extension's Options, pick Haiku (fastest, lightest on your usage limits), Sonnet, Opus, or Custom model ID for any model Claude Code accepts.

No Claude Code?

Choose Ollama (local or your own server) or Gemini Nano (Chrome's built-in model, where available) in Options. Neither needs the helper. Without any model, Tidy groups tabs by website when two or more sites have several tabs.

Remove the helper

curl -fsSL https://github.com/sanchitsharma/tidy-tabs/releases/latest/download/uninstall.sh | bash

Troubleshooting

  • "The Claude helper isn't installed for this browser": run the installer, then fully quit and reopen the browser.
  • "…installed, but not for this extension id": re-run the installer.
  • Still stuck? Click Copy diagnostics in the popup and open an issue.
