Tidy Tabs AI

Claude needs the Tidy Tabs AI helper, installed once (macOS or Linux): Setup guide. It uses your Claude subscription through claude -p; no API key.

Any model your Claude Code CLI accepts: an alias like sonnet or a full model ID.

Ollama

Pre-approved: http://localhost:11434. Any other endpoint (e.g. a Tailscale VM) is requested as an optional permission when you click Save.

Clustering

Two-pass constrains every tab to exactly one label via the schema, so small models drop and duplicate fewer ids.

After this, the extension falls back to grouping by domain. Covers both passes. Claude Haiku: ~5–10 s per call. CPU Ollama single-pass: 20–40 s for qwen3:1.7b, ~75 s for gemma3:4b.

Prompt

Sets {groups}. Lower means more, smaller groups; higher means fewer, bigger ones. Default 4 ().

Sets {maxGroups}, and is enforced: if the model returns more, the smallest groups go into "Other". Counts "Other". Default 8, up to 16.

Describe how you want your tabs grouped, in plain words. For example: "Keep work and personal tabs apart" or "Label groups in Spanish".

Optional placeholders (filled in each time you tidy, from the two numbers above):
{groups} → the suggested number of groups for that window ().
{maxGroups} → the maximum groups: .

Always added after your text, so tidying keeps working: use every tab once, at least 2 tabs per group, at most groups, and the reply format. Your text is sent to your chosen model along with the tab titles.
